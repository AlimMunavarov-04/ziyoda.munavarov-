# Правила для ИИ-помощников (Claude, Codex, Cursor и др.)

1. **Каждое изменение сайта сразу отражается в инструкции** — `data/help.js`
   (раздел «❓ Инструкция» на сайте):
   - новая или изменённая функция → обновить пункт в разделе нужной роли
     (`teacher` — учитель, `student` — ученик) или добавить новый раздел;
   - удалённая функция → убрать её из инструкции;
   - в `changes` добавить строку **сверху**: дата `ГГГГ-ММ-ДД`, `who` (`all` / `teacher` /
     `student`), что изменилось простыми словами.
   Изменение без обновления инструкции считается незаконченным.
2. Отвечать владельцу по-русски. Владелец не программист: всё, что требует сервера,
   давать одной готовой командой для PowerShell.
3. Тексты упражнений из книги Menschen не копировать (авторское право) — только страница,
   номер, порядок и описание своими словами. Слова и правила — свои.
4. Слова не повторяются между заданиями (это делает `build()` в `js/app.js` по `wordKey`).
5. Push в `main` = выкладка на https://ziyoda.munavarovbi.com через минуту (см. README).
   Перед push проверить в браузере настоящими кликами, а не только скриптом.
